# AGENTS.md

Guidance for coding agents working in this repository.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `abernier/material-theme-builder`, via the `gh` CLI. External
PRs are **not** treated as a request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical roles use their default strings — `needs-triage`, `needs-info`,
`ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
